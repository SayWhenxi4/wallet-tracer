# IC3 Complaint — Prep Sheet
*Fill this out first, in a separate tab/document. Then paste it into ic3.gov in one sitting.*

## Before you open ic3.gov
- **Use a laptop/desktop**, not a phone or tablet — the form is desktop-only.
- **There is no save-and-resume.** If your session times out from inactivity or you close the tab, you start over.
- **There is no file upload.** Screenshots, exhibits, documents — none of it attaches. Everything goes in as pasted text.
- Once you submit and see the confirmation page, **print or save it immediately** — the submission ID on it is your only reference number, and you cannot reopen that page later.
